PROCUREMENT FUNDING — IMPROVED PBIP PROJECT

OPEN
1. Extract this entire ZIP (do not open the PBIP from inside the ZIP).
2. Open Procurement_Funding_Improved.pbip in Power BI Desktop.
3. Keep the Report and SemanticModel folders beside the PBIP file.
Use the same or a newer Desktop release than the source file (September 2026).
If requested, enable the Power BI Project save option in Desktop settings.

The ZIP includes the imported data cache. Do not delete the .pbi/cache.abf file
if you want to retain the existing imported snapshot. Refreshing uses the
original Google BigQuery queries and requires your existing source access.

IMPROVEMENTS
- Three consistently styled 1600 x 900 report pages.
- Clear titles, readable typography, white panels and navy/teal/orange colours.
- Four KPI cards on every page and an awarding-agency dropdown per page.
- Daily trend explicitly sorted by date ascending.
- Shorter visual field labels, readable table styling and consistent spacing.
- Source, sampling and interpretation notes on every page.
- Original Top 10 filters, nine DAX measures and source queries preserved.

HOW TO USE
Select an agency in the dropdown; use its clear-selection control to reset.
The dropdowns are page-specific, not synchronized between pages.
Click bars to explore cross-filtering. Supplier concentration measures retain
their original definition: they ignore supplier filters, while respecting
agency/date context. Reductions are positive magnitudes; net obligations are
funding increases minus reductions. Offer-count coverage includes zero offers;
single-offer share uses only actions with one or more offers.

VALIDATION AND LIMITS
The project was reconstructed from the uploaded PBIX. All 6 model tables
(including 2 hidden date tables), 62 columns, 9 measure expressions, 4 source
queries and the decompressed imported cache were checked against the original.
Original chart filters, visual field references and page bounds were checked.
Power BI Desktop is not available in this environment, so native opening,
rendering, cache restoration and interactive behaviour have NOT been tested.
If Desktop reports an error, keep the original PBIX and share the error text.
The report uses the supported legacy report.json project layout and a model.bim
semantic model. You can save to newer project formats from Power BI Desktop.
